What Orbit is
What it does not promise

One command to install

A fresh Ubuntu or Debian server becomes a platform with Kubernetes (K3s), HTTPS and a console in about five minutes.

Applications from GitHub, GitLab, Bitbucket or an image

Builds on your server, HTTPS addresses, custom domains, variables and secrets, health checks, rollbacks, logs and autoscaling.

Managed databases

PostgreSQL, MySQL, MongoDB and Redis with credentials, references, upgrades and data browsing, and Spaces for files. PostgreSQL can run replicas on other servers.

Backups you can trust

Every backup is restored in isolation before it counts as verified. PostgreSQL restores to any second its archive covers.

Previews before changes

Resources, replicas and migrations show what they reserve, what pauses and what could go wrong before anything is applied.

Honest limits

Orbit measures failovers and says what was lost. It does not call anything high availability until losing any server passes on separate real servers.
